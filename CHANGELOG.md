# Changelog

## 0.1.0

- Initial release.
- Sync audiobooks flagged in Calibre (`#audiobook = Yes`) to a self-hosted
  Audiobookshelf server.
- Matching: Audible ASIN first, normalized title/author fallback.
- No local sync state -- Audiobookshelf's current library is always
  re-fetched live.
- Toolbar button with Configure / About / Help / Report a Bug menu.
